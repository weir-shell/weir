# Tooling

Reference is the language. Tooling is everything around it — the
pages here are for someone setting up a project, a pipeline, or an
editor, rather than someone writing a line of weir.

- [CLI](cli.md) — every subcommand and flag, pinned against the
  binary's own `--help`
- [Editors](editors.md) — per-editor LSP setup
- [The REPL](repl.md) — the interactive session's manual
- [Signatures](signatures.md) — check external tools' flags, not just
  their existence
- [Schemas](schemas.md) — vendored JSON schemas for `yaml` blocks
- [Project layout](project.md) — `.weir/`, the lock, what to commit
- [Configuration](configuration.md) — `WEIR_LOG` and the REPL config
