# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful; harassment and personal attacks are not
tolerated; disagreements are about code and ideas, argued with
evidence (this repo runs on receipts — bring them).

Reports: use the security/reporting channel in
[SECURITY.md](SECURITY.md) (GitHub private reporting or the
maintainer's email there); reports are handled confidentially.
